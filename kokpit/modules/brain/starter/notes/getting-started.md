# Getting started

This folder is your second brain. Kokpit reads it; it writes only through quick capture (a new file in `inbox/` or a checkbox line in `To-Do.md`).

The conventions that several AI agents can share are in the repository's `docs/brain-protocol.md`. In short: `Threads.md` says where each piece of work stands, `Last-Session.md` says what the last agent did, `To-Do.md` holds your open tasks.
